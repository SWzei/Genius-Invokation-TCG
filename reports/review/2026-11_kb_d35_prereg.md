# D35 预先登记：分歧点评测

> 写于 2026-11-22 17:40（太平洋时间），在任何分歧点探测与续打之前。
> 之前只在 1 局上做过冒烟（16 次模型调用；1 局 8 个局面，4 个分歧点），用来确认程序，不计入结果。
> 之后对本文件的改动只追加，并注明时间与原因。

## 1. 问题

D34 的整局成对对战：80 对的 95% CI 半宽约 ±0.06；三分之二的对两局结果相同，有效信息少。
分歧点评测的想法是：只在两个策略**同一局面下选择不同**的地方比较，从该局面分叉，两个分支由**同一个续打策略**替双方打完，差别只来自这一个决定。

要回答：

1. **可行性**：能否精确重放并分叉？分歧点多不多？续打结果是否对这一个决定敏感（决定性比例）？
2. **噪声**：模型在温度 0 下对同一局面的回答也不完全一致。用一个**完全相同配置的副本**（`none2`）当空白对照，看"分歧"里有多少是纯噪声。
3. **免费的脚本续打能否代替模型续打**（同号比例）？
4. **效率**：同样花费下，分歧点评测与整局对战谁的统计力更强？
5. **方向是否一致**：用它比较 v1.0 对无知识、v1.0-s1 对 v1.0，方向是否与 D34 整局结果一致（D34 两者都不显著，只能算弱检验）。

## 2. 数据与配置

- **局面**：只取 D34 的 `mirror_train` 带记录对局（`d34_ab_v10_train`，20 对 40 局，v1.0 对无知识）。dev / test 不用。
- **重放保真**：登记前已核对，40/40 局逐决策重放到相同胜者（`bench.forks.replay`）。
- **抽样**：每局每个座位从"非强制、≥ 2 个选项"的决策中取 8 个，均分成 8 段，每段随机 1 个，种子固定。最多 640 个局面，各类请求都包括。
- **被比较的策略**：都是 `deepseek-flash`，非思考，温度 0，`reply=reason_first`。

| 名称 | 规格 |
|---|---|
| `none` | `llm:deepseek-flash#reply=reason_first` |
| `none2` | 与 `none` 完全相同（空白对照） |
| `v10` | `llm:deepseek-flash#kb=kbt3-trig,reply=reason_first` |
| `s1` | `llm:deepseek-flash#kb=kbt4-s1,reply=reason_first` |

- **比较**：C0 `none2:none`（空白对照）、C1 `v10:none`、C2 `s1:v10`。分歧点只计两个策略都由模型作答（非回退）的局面。
- **续打**：
  - 脚本 `heuristic` 替双方续打，所有分歧点都做，免费；
  - 模型 `llm:deepseek-flash#reply=reason_first` 替双方续打，每个比较按固定种子抽至多 60 个分歧点，每个分支 1 次；其中前 30 个每个分支再打 1 次，用来测重打噪声。
- **分支差**：A 的选择续打得分 − B 的选择续打得分，从做决定的一方看，胜 1、平 0.5、负 0。

## 3. 判据（登记）

| 项 | 判据 |
|---|---|
| 空白对照 | C0 的平均分支差 95% CI 含 0；否则视为方法有偏，后面的结论都不成立 |
| 超额分歧 | C1、C2 的分歧率减去 C0 的分歧率，才是"策略真的不同"的部分 |
| 敏感性 | 模型续打的决定性比例 ≥ 20% 才有用 |
| 脚本续打能否代替 | 两种续打都有决定性结果的分歧点中，同号比例 ≥ 70%，且脚本续打的决定性比例 ≥ 20%，才可用脚本续打做初筛 |
| 效率 | 比较"平均效应 / SE"按每元折算，分歧点（探测 + 两支续打）与 D34 整局（对分标准差 0.58，每对约 0.5–0.65 元）对比 |
| 可用 | 同时满足：空白对照通过、敏感性达标、效率不低于整局，才建议把分歧点评测作为策略层门禁前的**初筛**。门禁本身仍用整局 |
