# D33 预先登记

> 写于 2026-11-22 02:10（太平洋时间），在任何 D33 候选的 dev 结果和任何新数据产出之前。
> 之后对本文件的改动只追加，并注明时间与原因。

## 1. 目标

在不过拟合的前提下，提升"带知识库的模型"的整体能力。

"整体"指整局胜率和斩杀转化，不只是情境规则题。情境规则题与 D32 的触发规则出自同一份设计，提升里可能有"对题"成分。

## 2. 数据的用途（D32 之后的状态）

| 数据 | D33 中的用途 |
|---|---|
| 场景集 v1、v2-train、情境题 train 部分 | 错误分析，可以随便看 |
| v2-dev、情境题 dev | 候选比较（dev）；只比较本文件登记的候选 |
| v2-test、情境题 test、`lite` 整局 | D32 已用过一次并公布，D33 不再当作保留数据；只作参考 |
| **场景集 v3**（新种子 `seed_offset=3000`，120 局源对局，整体作为保留集） | 最终评估，只跑一次 |
| **`lite_fresh` 整局**（`lite` 的结构，新种子 `seed_offset=200000`） | 最终评估，只跑一次 |
| **留出题型**（见 §4） | 只在 v3 上出题与评测；设计候选时不看它们的任何结果 |

## 3. 候选（只比较这些）

| 代号 | 配置 | 动机（来自 train / D32 公开结果） |
|---|---|---|
| B | `kbt-s4` + `reply=reason_first`（D32 选定方案） | 基线 |
| C1 | `kbt3-lean` + `reply=reason_first`：只保留规则（检索 + D32 情境触发），去掉策略单元与斩杀窗口资料 | D32：S1–S3 无收益；原接入在斩杀上把回合花在铺垫上，理由与策略观点一致；输入更短 |
| C2 | `kbt3-trig` + `reply=reason_first`：B 再加一条触发——对方未宣布结束且我方可宣布结束时注入 R01 §4.2 | D32 失误 `lethal-0126`：对方仍能行动时宣布结束，指望结束阶段斩杀 |
| C3 | `kbt-s4` + `reply=checklist`：先写依据时按固定清单（能否本行动轮击倒或赢下、对方是否已结束、骰子与费用） | v1 train 斩杀失误：约 8/15 没算到结束阶段伤害，其余是算错 |

若 C1–C3 中有两个各自通过 §5 的规则，允许再在 dev 上加测一次两者的组合，组合同样要通过 §5。不再加其它候选。

## 4. 留出题型（检验是否只对设计过的题有效）

只在 v3 上出题。答案同样由程序按规则表和可见状态算出。

| 题型 | 依据 | 被哪些候选的注入覆盖 |
|---|---|---|
| `first_next` 下一回合先手 | R01 §4.2 | C2 的新触发会注入 R01 §4.2（已知污染，单列报告） |
| `energy` 用技能后的充能 | R03 §2 | 只能靠检索 |
| `hand_limit` 抓牌后的手牌数 | R01 §5 / R07 §1 | R07 §1 在我方召唤物 ≥ 3 时由 D32 触发注入（少见） |
| `dice_cap` 获得骰子后的骰子数 | R02 §1 / R07 §1 | 同上 |
| `tuning` 元素调和的结果 | R02 §5 / R03 §2 | 只能靠检索 |

另外修正一处题目缺陷（只用于 v3 题库）：`charged`（重击）题只在我方骰子 ≥ 3 时出。骰子为 0–2 时普攻本身打不出，"是否视为重击"是空设问题；D32 train 的失误里有一半是这种题。

## 5. 选择规则（dev）

指标：
- 情境题 dev，先写依据模式，245 题 × 2 轮；C3 不改变情境题，记为与 B 相同。
- 斩杀转化 dev，64 题 × 2 轮。

候选 X 替代 B 的条件：Δ情境 ≥ 0 且 Δ斩杀 ≥ 0，至少一项 > 0；或两项之和 ≥ +0.02，且没有一项 < −0.02。
多个候选通过时，取两项之和最大者；相同时取每次输入 token 更少者。都不通过就保留 B。

## 6. 最终评估（新数据，只跑一次）

- v3 情境题：原题型与留出题型。配置为 无知识 / 选定方案，直接作答与先写依据两种模式，2 轮。
- v3 斩杀转化：无知识 / B / 选定方案（若与 B 不同），2 轮。
- `lite_fresh` 整局：无知识 / 选定方案，各 2 轮（112 局 × 2）。
- 跨模型：GLM-4.7-Flash（免费档、非思考）在 v3 情境题上跑 无知识 / 选定方案 的知识，先写依据，1 轮。看收益是否只属于 DeepSeek。

预算约 30 元，主要花在整局上；超出前先问。
